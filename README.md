# Drag & Drop List – React + TypeScript

This is a simple project that creates a drag-and-drop list using **React**, **TypeScript**, and **Vite**.  
It uses native HTML5 drag events with basic logic to support nesting and movement of items.

---

## 🛠️ Getting Started

1. Install dependencies  
```bash
npm install
```
2. Run Server
```bash
npm run dev
